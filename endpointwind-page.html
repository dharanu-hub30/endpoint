VI Minimum Underpinning Theory

The development of webpages for endpoint data management using JavaScript is fundamentally rooted in several core theories and concepts that enable dynamic, interactive, and efficient web applications. These underpinning theories focus on how client-server communication works, the importance of asynchronous programming, and the principles of data flow in modern web applications.

  • Client-server communication
  • HTTP methods
  • Asynchronous programming
  • Promises & async/await
  • JSON
  • Data flow

VII Practicum Set-up

Architecture of the endpoint system. Use the buttons to send a request through it and watch the data flow light up.

  1. 1 Devices send requests through Cloud CDN, then Cloud Load Balancing.
  2. 2 Static pages and files are served from Cloud Storage.
  3. 3 Data requests are routed to the Cloud Run service.
  4. 4 Cloud Run reads and writes turbine records in Cloud Firestore.
  5. 5 Secret Manager gives Cloud Run its credentials securely.
